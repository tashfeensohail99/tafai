## WEEK 2 APPROVED TASKS ONLY

Week 2 must only cover:

1. Repository and branch strategy
2. NestJS backend foundation (TypeScript strict, health check, error handler, validation)
3. PostgreSQL database migrations (auth, org, RBAC, audit, timeline tables)
4. Users, roles, permissions, departments, employees base
5. Auth module (login, logout, refresh, me, password reset)
6. RBAC guard (permission check + ownership check on every protected route)
7. Audit log foundation (immutable, all auth and user/role/department events)
8. Activity timeline foundation (separate from audit, business-readable events)
9. Private file storage foundation (no public URLs, signed URLs only after permission check)
10. Next.js frontend shell (role-aware sidebar, light/dark theme, shared layout)
11. Design tokens and shared UI components (StatusBadge, DataTable, Button, Input, FilterBar)
12. Staging deployment baseline and Flutter shell/auth contract

Nothing else. No feature screens on top of an incomplete foundation.
